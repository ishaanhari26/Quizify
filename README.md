# Quizify - AI-Powered Study Application

*This is a fork of the main repo: [Rishi-S20/Quizify-App](https://github.com/Rishi-S20/Quizify-App)*

## Description
Quizify transforms traditional studying through AI-generated flashcard sets, 
interactive games, progress tracking, and social features.

## Features
- 🤖 AI-Generated Flashcards using Google Gemini API
- 🎮 Interactive Matching Games & QuizRooms (Kahoot-style)
- 📊 Comprehensive Analytics & Study Streaks
- 👥 Social Discovery & Community Features
- 🔐 Secure Authentication with 2FA Support

## Technology Stack
- **Frontend:** SwiftUI (iOS)
- **Backend:** Firebase Firestore
- **Authentication:** Firebase Auth with 2FA
- **AI Integration:** Google Gemini API
- **Architecture:** MVVM Pattern

## Installation
1. Clone repository: `git clone [repository-url]`
2. Open Quizify.xcodeproj in Xcode
3. Configure Firebase with GoogleService-Info.plist
4. Add Gemini API key to environment variables
5. Build and run on iOS device/simulator
